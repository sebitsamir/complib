Getting started

Introduction to FlowStack

FlowStack helps teams automate workflows across CRM, billing, and support tools. This guide walks you through setup in under 10 minutes.

Prerequisites

  • A FlowStack account (free tier works)
  • Admin access to your CRM or data source
  • Node.js 18+ for the CLI (optional)

Install the CLI

npm install -g @flowstack/cli
flowstack login
flowstack init my-workspace
